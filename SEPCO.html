📈 Overview - Plan vs Actual per Specialized Trainer

Same rules as ST dashboards (Content Developer · SES/NSO/CX · S+ Expert/Admin): category buckets, approved-content minutes, productivity & efficiency.

📝 Computation Guide & Notes (same as ST)
  • Category bucket: Uses CATEGORY 2 first if it is CONTENT / TASK / OTHERS / TRAINING; otherwise CATEGORY. Detailed types like “CONTENT - One-Pager Templated” are not counted as CONTENT unless CATEGORY 2 says so.
  • Target Count: Sum of Monthly Plan FREQUENCY PER MONTH per bucket.
  • Actual Count: CONTENT = Approved items (from Approvals sheet or Daily Actual with APPROVAL DATE / matching Approved file) and its Category 2 must exist in that trainer's Monthly Plan; not yet approved or not in the Monthly Plan = not counted. TASK / OTHERS / TRAINING: unique units only — the same title on the same day counts once (not per submission), it must match a line in the trainer's Monthly Plan (Category 2, then title), and each plan line is capped at its Target Count, so Achievement % cannot exceed 100%. Minutes are unaffected.
  • Plan Minutes: FREQUENCY × DURATION PER MIN (defaults to 480 × frequency when duration is blank).
  • Actual Minutes: DURATION PER MIN from Daily Actual, unique rows only (an exact duplicate time block counts once). CONTENT count and minutes count only after Approved (APPROVAL DATE on the Daily Actual row, or a matching Approved file in Approvals — same rule as all ST files). Only actuals that are in the trainer's Monthly Plan are shown here; hover the cell to see the logged / excluded minutes.
  • Achievement %: Actual Count ÷ Target Count × 100 (— when target is 0).
  • On Time / Late: One result per unique Daily Plan item (user + date + title; several time blocks add up). On Time = actual duration < plan duration; Late = actual > plan.
  • Designated Minutes: (working days − approved leave) × 480. This is the gate for the two rates below.
  • Productivity: Counted Actual mins ÷ (Monthly Plan mins − leave × 480) × 100. Only actuals in the Monthly Plan count. If the Monthly Plan is below Designated Minutes, actuals not in the plan are excluded and Productivity cannot go over 100%. Once the Monthly Plan meets Designated Minutes, actuals not in the plan are added on top (plus to productivity), so over-achievement is possible.
  • Efficiency: Unique Daily Plan mins ÷ their Daily Actual mins × 100 (each Daily Plan item matched once). Same gate: plan below Designated → only Monthly-Plan items count and it is capped at 100%; plan meets Designated → all matched items count and it can exceed 100%.
