ℹ️ How is this computed?
📌 Content count
  • Target no. of content = Monthly Plan rows (category CONTENT) for the selected MONTH × FREQUENCY PER MONTH.
  • Actual no. of content = your Daily Actual rows with category CONTENT (one per “Is this the start date? = Yes”; if not used, one per title). Titles/category containing “proofread” count as Proofread, not Own Content.
  • A content is counted only once it is approved: APPROVAL DATE is filled in, or an Approved file in Approval Requests has the content title in its name. Otherwise it stays in Awaiting approval.
  • Ach % = Own Content ÷ Target.
⏱️ Accuracy · Efficiency · Timeliness
  • Target Count (Content) % = Own Content ÷ Target. Target = Monthly Plan rows (category CONTENT) for the selected MONTH × FREQUENCY PER MONTH.
  • Accuracy (Quality) % = (Target − Revision count) ÷ Target. Revisions = Rejected files in Approval Requests that match Monthly Plan by file name (vs plan TITLE) or by category (vs plan CATEGORY). Unrelated rejects are ignored. Less the Content Errors deduction (1–2 errors = 1%, 3–4 = 2% …).
  • Efficiency % = Total duration of actual approved content ÷ Monthly Plan total duration (CONTENT rows: DURATION PER MIN × FREQUENCY PER MONTH).
  • Timeliness (On-time) % = Daily Actual total duration ÷ Daily Plan total duration (both use DURATION PER MIN for the selected month).
⚡ Productivity Rate (15% weight)
  • Productivity = Daily Actual duration ÷ (Monthly Plan duration − leave/absent × 480), cap 100%. Included in Total KPI.
  • Actual Duration = sum of DURATION PER MIN from Daily Actual. CONTENT counts only when approved; TASK / OTHERS always count.
  • Adjusted Planned Duration = Monthly Plan minutes (frequency × duration) less leave / absent days (480 mins each).
