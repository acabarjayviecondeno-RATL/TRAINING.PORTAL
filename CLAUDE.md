# Project Instructions

Before modifying any HTML, CSS, JavaScript, or application
logic, read and follow `awesome-design.md`.

## Mandatory Rules
- Preserve all existing business logic and functionality.
- Preserve Google Sheets integrations, Apps Script calls,
  API connections, filters, calculations, and event handlers.
- Focus on UI/UX improvements unless functional changes
  are explicitly requested.
- Do not remove existing features or replace live data
  with mock data.
- Inspect the relevant files before making changes.
- Make minimal, focused, and responsive changes.
- Test affected functionality and report any issues.
- Provide the complete revised files when requested.
